# Portafolio personal

Este es mi portafolio personal desarrollado como proyecto web responsive.  
El sitio presenta información sobre mí, mis habilidades, herramientas y proyectos destacados.

## Enlace al sitio

Puedes verlo publicado en GitHub Pages aquí:

[Ver portafolio en vivo](https://ja-ardila.github.io/web_project_portfolio_es/)

## Tecnologías utilizadas

- HTML5
- CSS3
- Metodología BEM
- Flexbox
- CSS Grid
- Git y GitHub
- GitHub Pages

## Características

- Diseño responsive para móvil, tablet y escritorio.
- Uso de fuentes locales en formato `.woff` y `.woff2`.
- Organización de estilos con metodología BEM.
- Sección de presentación personal.
- Sección de habilidades y herramientas.
- Sección de proyectos destacados.
- Sección de contacto.
- Diseño basado en el archivo Figma suministrado.
